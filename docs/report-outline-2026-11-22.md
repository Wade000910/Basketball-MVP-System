# 專題報告大綱（依農化同學國科會成果報告的格式）

格式參考：封面 → 摘要 → 目錄／圖目錄／表目錄 → 研究背景與目的 → 設計與架構 → 材料與方法 → 結果與討論 → 結論 → 進度與後續 → 參考文獻。
學校另要求「專案管理」章節，加在結論之後。寫法：結果保守、限制照實寫、每張圖表有編號與說明；數字只來自實際資料。
