# Basketball MVP｜球員訓練室

記錄每一球，回看自己的訓練進度。支援罰球、中距離與三分球練習，提供逐球記錄、個人統計、訓練報告與罰球動作分析。

**[立即開始訓練](https://wade000910.github.io/Basketball-MVP-System/training/)** · [網站首頁](https://wade000910.github.io/Basketball-MVP-System/)

## 開始使用

1. 開啟球員訓練室，輸入自訂學員代碼，例如 P001。
2. 選擇罰球、中距離或三分球，設定目標球數與今天的練習重點；中距離與三分球可再選左側、中央或右側。
3. 每次投籃後，由自己或教練按大按鈕「命中」或「未中」。畫面會顯示已記錄的球次；誤記時可撤回、修正或刪除。
4. 結束練習，查看命中率、同類型上一組的比較及本組動作摘要，下載報告或列印成 PDF。
5. 下次使用相同代碼，回看近七天進度，或按「同設定再練一組」繼續練習。

第一次使用可以先開啟示範報告，熟悉操作。示範報告使用合成資料，與自己的訓練紀錄分開。

## 功能

| 功能 | 使用方式 |
| --- | --- |
| 球員首頁 | 查看近七天進度、最近 10 組命中率折線與各位置累積 |
| 投籃練習 | 設定 10、20 或 30 球目標及投籃位置，以大按鈕記錄命中與未中 |
| 多組計畫 | 排好最多 10 組訓練，完成一組後自動進入下一組，回看合計報告 |
| 紀錄修正 | 撤回最後一球，或修正、刪除指定球次 |
| 訓練報告 | 一起回看命中紀錄與同組動作摘要，下載 JSON、CSV 或列印 PDF |
| 歷史紀錄 | 保存最近 30 組，重新開啟頁面可接續練習或回看報告 |
| 罰球動作分析 | 自動填入訓練代碼，依入鏡提示調整拍攝，選擇聲音或視覺回饋 |
| 影片回看 | 匯入已下載的影片與分析資料，逐格檢視、對齊與標記事件 |
| 備份與匯入 | 下載全部訓練備份，或將 JSON 報告匯入另一台裝置 |
| 離線訓練 | 連線準備一次後，離線記錄、查看報告與備份；可加入手機主畫面 |

## 安排今天的多組訓練

填入學員代碼，展開「安排多組訓練計畫」。預設為罰球 10 球、中距離 20 球及三分球 20 球，可調整位置、球數與練習重點，也能新增或移除組別。

按「開始整份計畫」後，每組按「結束本組並進入下一組」即可繼續。重新開啟頁面會接續目前組別；提前結束一組會保留實際球數。最後一組結束後，計畫卡片顯示已完成組數、總球數與合計命中率。

可隨時結束計畫，已完成的報告會保留。按「下載計畫與報告」可帶走整份計畫，匯入後也能接續未完成的組別。目前頁面保留最近一份計畫；開始新計畫後，先前已完成的各組仍在歷史中，可事先下載計畫報告保存。

## 手機離線使用

先連線開啟訓練室，等畫面顯示「已備妥離線訓練」。之後即使沒有網路，也能重新開啟訓練頁、接續計畫、記錄投籃、查看報告與下載／匯入備份。

- Android：在 Chrome 選單選擇安裝／加入主畫面；瀏覽器提供安裝提示時，頁面也會顯示安裝按鈕。
- iPhone：在 Safari 按分享，再選「加入主畫面」。
- 離線功能涵蓋球員訓練室；相機分析與影片回看請在連線時開啟。
- 清除網站資料也會移除離線檔案及訓練紀錄，請先下載備份。

有新版時，頁面會提示更新；完成練習後關閉所有訓練頁，再重新開啟即可使用新版。更新不會自動重載正在練習的頁面。

## 場邊記錄與趨勢

按下命中或未中後，會顯示「已記錄第幾球」及下一球編號。快速重複按壓會只記一球，誤記可立即按「撤回最後一球」重新記錄。

投籃位置以球員面向籃框的方向區分，每組固定一個位置；換位置時可開始新一組。罰球固定為中央。位置會保存在歷史、JSON、CSV 與完整備份；舊的中距離或三分紀錄保持「未標記」。

在球員首頁選擇投籃類型與位置，即可查看有投籃紀錄的最近 10 組命中率折線及逐組球數。各位置命中率依總命中／總球數計算，使用此瀏覽器保存的全部已完成紀錄。報告的上一組比較限同代碼、同類型與同位置。

## 相機與影片

在罰球練習中按「開啟罰球動作分析」，會另開分析頁並帶入本組代碼。選擇慣用手與回饋方式，按「開啟相機並開始」。將手機固定在慣用手側，讓肩膀到腳踝入鏡，依畫面提示調整位置。

停止分析後，回訓練室即可看到本組動作摘要；JSON 訓練報告和完整備份會包含這些摘要。每次分析最多保存 200 個試次，本機動作摘要保留最近 30 次；影片仍需在分析頁另行下載。命中結果由你或教練手動記錄，與動作試次分別編號。

訓練代碼已自動填入。需要調整代碼、相機縮放、查看裝置資訊或逐次 CSV 時，可展開進階選單。從訓練室開啟的學員與訓練代碼會固定，保持報告歸屬一致。

動作頁的 Δt 表示「手肘伸展起始時間－膝部伸展角速度峰值時間」，用於回看兩個動作的先後與間隔。聲音依畫面顯示的時序區間切換。

需要回看影片時，在動作頁下載本機影片與資料套件，再前往[影片回看工具](https://wade000910.github.io/Basketball-MVP-System/offline-review/)選取同組檔案，依指引設定時間對齊。

## 換裝置與備份還原

在訓練室的「備份與匯入」按「下載全部訓練備份」，將 JSON 保存至自己的裝置。到另一台裝置開啟訓練室，選取這份檔案即可還原歷史與未完成練習；單組 JSON 訓練報告也可匯入。

匯入前會檢查資料格式與訓練歸屬。相同訓練代碼保留目前裝置的版本；若與正在進行的練習衝突、超過 30 組歷史或檔案超過 5 MB，會提示原因並保留原紀錄。示範報告不會匯入正式歷史。

## 裝置與資料保存

- 手機或電腦皆可開啟；Android 使用 Chrome，iPhone 使用 Safari。
- 訓練頁不需要相機。動作分析頁需要網路連線、HTTPS 與相機權限。
- 命中由使用者或教練手動記錄，統計會隨修正同步更新。
- 紀錄保存在目前裝置與瀏覽器，沒有帳號或跨裝置同步；共用裝置可看到本機歷史。
- 使用自訂代碼即可，請勿輸入真實姓名。清除網站資料會刪除紀錄，建議定期下載報告。
- 影片與分析檔由使用者在本機下載及選取，檔案不會上傳至伺服器。

## 本機開發

以本機 HTTP 伺服器開啟儲存庫，進入 training/。相機功能請使用 localhost 或 HTTPS。

程式檢查：

```bash
npm test
```

修改訓練頁的 HTML、CSS、JavaScript、圖示或 manifest 後，先執行 `node tools/update-offline-shell.cjs` 更新離線快取版本，再執行測試。版本依檔案內容計算，測試會阻止漏更新的離線版本。

瀏覽器流程檢查需 Node.js 22 以上及 Chrome／Chromium，設定 BROWSER_BIN 後執行：

```bash
node tools/training-browser-smoke.cjs
```

開發紀錄與技術資料保存在 [docs/](./docs/)，歷史版本可由 Git 記錄查閱。
