# 2026-10-16：第 1 項，區分無效時序與真正 0 ms

狀態：已實作及本機驗證，供 PR 審查；尚未合併或部署。

原問題：NaN 或恆定角度可能回傳 0 ms；缺少手肘起始事件時改用峰值時間。無法計算的試次原本不保留。

本次變更：

- 至少 10 筆有限角度／時間資料，時間必須嚴格遞增。
- 插值後速度必須有限；必須有正向膝伸展及超過既有 10 deg/s 門檻的肘伸展。
- 視窗最後一點的最大值視為峰值尚未確認；肘起始必須在實際視窗內觀察到門檻 crossing，不採插值邊界外推。
- 無效試次保留 `trialStatus=invalid`、`dt=null`、原因與 `result=not_calculated`；無成功／失敗音效，不更新 SD/CV，後續統計也排除非有限 dt。
- 真正同時發生的事件仍可得到 0 ms。非有限原始角度不進入持續使用的濾波器；已確認試次結束並進入無效結果流程。
- 演算法識別更新為 `timing-validity-v2`，包含 session manifest。

未變更：50–150 ms 未驗證目標範圍、濾波器、既有角速度門檻、CV 公式、低品質試次統計政策。

驗證：修改前 31 項 Node 測試、HTML/Pages 檢查通過。修改後新增實際內嵌函式測試，包含 NaN/Infinity/恆定角度/不足筆數/重複時間、缺少起始／截斷峰值、真 0／正負時差、無效與真 0 的回饋分支。事件時差測試使用可控制的插值輸出；不是實機準確度驗證。
