# 離線逐格檢查頁：參考檢查與整合方向

日期：2026-10-06。狀態：已完成外部 HTML 的程式與資料結構檢查；以下整合功能仍為規劃，尚未實作。

## 已確認的決定

外部投籃分析頁可以參考其內容組織與互動呈現，但關鍵分析邏輯使用本專案的方法。既有投籃候選確認與狀態流程、膝肘事件定義、`deltaT`、品質規則及回饋判定是接續工作的基準；必要修正仍依本專案驗證清單處理。

原始 HTML、影片、影格圖片、個人動作分析數值及本機來源路徑不納入公開 repository。本頁只記錄去識別的檢查結論與設計決定。

## 外部參考的檢查結果

- JavaScript 語法與程式中固定 DOM ID 引用通過檢查，內嵌圖片與影片可解碼。未完成瀏覽器逐項操作或手機驗收。
- 頁面平均值與標準差能由預存資料重算一致；這只確認顯示算術，不證明原始動作量測準確。
- 頁面讀取預存球路、骨架及相機參數；未提供匯入新影片後重新追蹤、姿態推論或軌跡擬合的流程。
- 起跳、最高點與落地使用所有試次共用的固定影格偏移，不能作為本專案的逐試次事件判定。
- 手動畫出的量測點未綁定試次或影格，切換後仍保留，存在跨畫面誤用風險。
- 零長度角度向量的測試得到 90 度；應判為無效輸入，而非顯示有效角度。
- 實際距離與角度依賴相機參數及平面假設。預存模型的合理性與量測準確度尚無獨立驗證，不能套用到其他影片。

不將球與球的標準差當作量測不確定度，不以像素擬合殘差宣稱實際空間量測準確，也不從身體與球速度的比值直接推論力學貢獻或訓練效果。

## 建議首版範圍與驗收

建立獨立的本機離線檢查頁，先讀取來源影片與本專案匯出資料，不改動即時回饋流程。

- [ ] 驗證輸入檔案屬於同一 session，缺檔或時間不匹配需明示。
- [ ] 逐格查看來源影片，顯示匹配的時間戳、骨架、訊號及品質標記；不得靜默配對到錯誤影格。
- [ ] 支援人工事件標註；正式誤差評估的標註模式須能隱藏演算法結果。
- [ ] 標註綁定來源與影格，換球或換影格時不顯示其他畫面的量測點。
- [ ] 匯出人工標註及事件差異表，原始即時結果保持獨立。
- [ ] 明確區分「查看既有資料」與「完整影片重新執行姿態與分析方法」；首版檢視頁不能取代完整重播工具。
- [ ] 同步與事件比較的數值容許範圍需先定義，再進行驗收。

檢視頁支援問題追查，不自動證明姿態、時序量測或回饋有效。兩次動作的視覺疊圖也不是獨立量測真值。

## 工作順序

先完成最新版手機短測與必要品質／回饋修正，再建立離線檢視與人工標註功能。其後補完整影片重播，依固定版本與參數完成量測驗證。維持原有 [剩餘測試清單](./remaining-tests-2026-10-02.md) 的驗收要求，不將本次參考檢查當成新的裝置實驗。
