# 球員訓練室：老師檢查展示

## 這次完成的功能

本專題從動作分析研究原型延伸為球員可操作的投籃訓練網頁 App。入口為 `training/index.html`，不需帳號或安裝套件。

1. 球員首頁：輸入學員代碼，顯示近 7 天完成組數與球數，以及罰球、中距離、三分球各自的累積命中率。
2. 訓練設定：選投籃類型、10／20／30 球與本組練習重點。
3. 場邊記錄：大型命中／未中按鈕、撤回、逐球修正及刪除；未完成可恢復或確認放棄。
4. 報告：球數、命中率、同代碼同類型的前一組比較，JSON／CSV 匯出與列印 PDF。
5. 快速換組：同設定再練一組，保留代碼、類型、目標與重點，重新開始計球。
6. 本機歷史：最近 30 組，重新整理後保留；舊版罰球紀錄仍可讀取。

## 三分鐘展示

1. **30 秒，產品方向。**「我想做給籃球人的訓練 App，先把個人投籃訓練的記錄和回顧做成完整流程。」開啟球員首頁。
2. **30 秒，先展示報告。**按「先看示範報告」，指出 70% 是合成示範資料，示範下載或列印。示範不進入正式歷史與個人統計。
3. **60 秒，實際操作。**更換設定，輸入 `P001`，選三分球與 10 球。記錄命中、未中，示範撤回與修正；提前結束，產生報告。
4. **30 秒，持續使用。**按「同設定再練一組」，再記幾球並結束，展示同類型跨組比較與球員首頁更新。重新整理證明本機恢復。
5. **30 秒，專題特色與下一步。**開啟既有相機分析入口，說明後續要把同一組訓練的人工紀錄與影片配對，並找球員實測操作是否打斷練習。

## 明天前準備

- 先在展示電腦用本機 HTTP 開啟整個專案：於專案目錄執行 `python -m http.server 8080 --bind 127.0.0.1`，再開 `http://127.0.0.1:8080/training/`。這需要電腦已安裝 Python。
- 練習頁資源皆在專案內，沒有 CDN 依賴；保留整份專案作為網路異常時的展示備份。相機分析仍有自己的網路及權限需求。
- 展示前走過一次流程，保存合成示範 PDF。新版本未合併到 `main` 前，公開 Pages 網址仍是舊版。
- 個人資料僅在目前瀏覽器，尚無雲端同步、安裝式 PWA 或完整離線快取；勿輸入真實姓名。
