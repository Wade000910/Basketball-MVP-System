## 後續節點（日期待排）

1. **展示前：**完成最新版本手機回歸、穩定展示版本、同串流錄影與資料匯出、最小離線重播、相機位置初測，以及手機喇叭和 AirPods 的初步延遲表徵。
2. **展示後：**完成分開拍攝的高影格率參考影片、逐格人工標註與事件偵測驗證；再依證據完成相機和聲音延遲測試。
3. **研究準備：**凍結演算法與裝置設定，完成可用性、研究流程、倫理與資料管理閘門。
4. **之後再決定：**依序進行可行性研究、回饋效果研究，最後評估是否擴大部署。未通過前置閘門前不開始參與者收案，也不宣稱療效或訓練成效。
