# 罰球投籃頁實測清單

頁面：`shoot/`。電腦上的自動測試已涵蓋流程，但以下幾點只能在真的手機和球場上確認。每一項記下手機型號、瀏覽器版本與結果。

## 1. 相機與速度

| 項目 | 怎麼做 | 記錄 |
| --- | --- | --- |
| 影格時間 | 練習一組後到球員首頁下載 JSON，看試次的 `timestampSource` | `camera-frame` 或 `pose-result` |
| fps（語音關） | 關掉「用說的記錄進球」，投 10 球，記畫面右上角 fps | 平均 fps |
| fps（語音開） | 開啟語音，同樣投 10 球 | 平均 fps，和上一列比較 |
| 量到比例 | 一組 20 球中，有幾球顯示節奏（不是「沒量到」） | n / 20 |

如果語音開啟時 fps 低於 24（試次會被標成畫面太慢），這台手機改用隊友幫記或按鈕。

## 2. 語音辨識

投 20 球，每球投完說「進」或「沒進」，另外由旁人用紙筆記真正的結果。

- 正確：頁面記錄和紙筆一致的球數。
- 錯誤：聽成相反結果的球數。
- 漏聽：沒有記錄、需要改按按鈕的球數。

在安靜場地與有其他人在打球的場地各做一次。報告中寫成「語音記錄正確率 x/20（安靜）、y/20（吵雜）」。

## 3. 聲音回饋

- 開啟語音後，「叮／嗡」是否仍聽得清楚（iPhone 開麥克風時，系統可能把喇叭音量降低）。
- 戴藍牙耳機時，聲音是否明顯延遲。可用慢動作對照頁標記聲音出現的那一格來量。

## 4. 隊友幫記

- 投籃者登入後按「隊友幫記」，隊友手機開 `shoot/mark.html` 輸入記錄碼。
- 記下隊友按下到投籃者畫面出現的延遲（約 2 秒內為正常）。
- 投籃者和隊友同時記同一球時，只會算一次。
