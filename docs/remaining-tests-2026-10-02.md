## 七項剩餘測試

### 1. 最新版手機回歸與實際出聲

- [ ] 確認公開建置與記錄版本，先在手機喇叭確認測試音，再另外測 AirPods Pro 2。
- [ ] 做 3 次非投籃動作與 5 次正常投籃，記錄實際出手數、系統試次數與可聽回饋。
- [ ] 檢查誤觸發、漏判、重複、提早回饋；固定參數，不在同一次測試同時調多個門檻。
- [ ] 保存新版完整八檔，核對影片、檔案大小、筆數、Session 條件及時間連結。

**預期：**指定非投籃動作不產生試次或聲音；正常投籃各產生一個試次，聽覺模式按有效試次規則回饋一次。若出現低品質、缺檔或異常，保留紀錄並修正後重測。這是新版驗收，不是宣稱八檔匯出從未完成。

### 2. 五分鐘效能比較

- [ ] 完成第 1 項短測後，比較「只分析」與「分析＋錄影＋資料記錄」。
- [ ] 在可比較的裝置、相機位置及動作安排下，記錄 FPS、分析耗時分布、長停頓、發熱、瀏覽器穩定性及有效資料產出。
- [ ] 核對完整停止與下載流程；明列加入錄影後的效能差異。

**完成條件：**兩種配置都有可追溯資料，未隱藏失敗或效能下降；可接受的下降範圍須事先決定。已有的 Phase 0 初次五分鐘診斷不重列為未完成。

### 3. 完整影片重播比較

- [ ] 先補影片與 manifest 輸入、逐影格分析及結果匯出的重播工具。
- [ ] 在 TUF 重播至少一組來源影片，以時間戳匹配試次，檢查遺漏或重複。
- [ ] 比較即時與重播的膝蓋事件、手肘事件及 `deltaT`。
- [ ] 同一影片、版本與參數重播兩次，檢查明確數值容許範圍內的一致性；原始即時結果不覆寫。

**完成條件：**有重播結果與差異表；同來源一致性不能當成獨立量測準確度。

### 4. 相機位置測試

- [ ] 預先選少量距離、高度、水平角度與直／橫向組合，以固定支架測試。
- [ ] 記錄全身可見度、遮擋、關鍵點可見度、缺失影格與有效試次比例，保留各位置結果。
- [ ] 選定可重現的架設方式，記錄尺寸、方向與淘汰其他位置的原因。

**完成條件：**架設能依紀錄重現，選擇有資料支持，不以後續效果結果調整位置。

### 5. 聲音延遲測試

- [ ] 先補閃光／短起音聲音校正與各處理階段的延遲記錄工具。
- [ ] 先手機喇叭，再 AirPods；用 A60 記錄閃光與實際聲音，在 TUF 檢查。
- [ ] 重複量測延遲中位數、分布、最大值、波動及漏音；保留原始媒體時間。
- [ ] 程式設定的 1 秒等待與處理／輸出延遲分開報告。

**完成條件：**各輸出路徑有重複觀察。A60 影格間隔與未知影音偏差須列出，稱為未校準的低成本延遲估計，不宣稱毫秒精準量測。

### 6. 慢動作影片量測驗證

- [ ] 在選定位置另錄 iPhone 原生 120／240 fps 影片，檢查原始影片時間與中繼資料。
- [ ] 定義膝肘事件，人工標記時隱藏演算法結果；隔一段時間重標隨機子集，檢查標記重複性。
- [ ] 比較同一慢動作影片內的演算法與人工事件，報告時間誤差、偏差、有效比例、失敗原因及不確定性。
- [ ] 比較來源取樣率、濾波設定及有／無插值；固定版本與參數後再做效果研究。

**完成條件：**有事件誤差及可靠性分析。這是另外拍攝的離線驗證，不得與不同次即時投籃假裝配對，也不是實驗室動作捕捉真值。

### 7. 三種模式實機驗收

- [ ] 無回饋模式不顯示動作結果、時間差、角度、SD/CV、圖表或聲音。
- [ ] 視覺與聽覺使用相同回饋資訊、名義等待時間；聽覺不在動作進行中回饋。
- [ ] 每個有效試次只回饋一次；低品質資料不給正常二元回饋。
- [ ] 模式切換、區塊重置與匯出標籤正確；統計不混合不同條件。
- [ ] 測試者能辨識聲音並理解流程，操作警告不洩漏禁止顯示給投籃者的資訊。

**完成條件：**腳本檢查與手機實測都通過。已完成的模式遮蔽單元測試不取代這項整體驗收。

## 測試前或測試期間必要修正

- [ ] 將低品質判斷移到正常回饋之前，再針對低 FPS／低可見度確認沒有錯誤正常回饋。
- [ ] 處理 CV 在平均時間差接近零或為負時的解釋與顯示，重新檢查邊界情況。
- [ ] 決定有依據的回饋內容。未驗證的 50–150 ms 不得當作通用姿勢正確標準；目前「正確／失準／時序完美」文字須相應修正。
- [ ] 補第 3、5 項所需工具後才進行相應驗收；不將尚未存在的工具列為完成。

## 七項通過後仍需完成的研究工作

1. 與指導老師固定研究問題、主要指標、樣本數依據、條件順序、熟悉練習、投籃次數、休息、有效資料及排除規則、認知負荷量測、同意與所需倫理／行政程序。
2. 固定演算法、裝置、回饋規則與介面；進行小型可行性試驗，檢查流程、疲勞、資料產出與技術失敗。
3. 按固定方案正式比較無回饋、視覺及聽覺條件，報告結果及限制；若討論學習效果，包含保留或遷移測試。

七項是技術與流程驗證，不等於整個研究結束，也不自動證明訓練有效。任何驗收失敗都須保留紀錄、評估修正並重測。
