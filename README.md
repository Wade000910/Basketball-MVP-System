# Basketball MVP｜個人與球隊的投籃訓練系統

一支手機記錄每一球、分析罰球出手動作；加入球隊後，教練能看到全隊的練習量、命中率與進步。個人使用不需要登入。

**[立即開始訓練](https://wade000910.github.io/Basketball-MVP-System/training/)** · [教練總覽示範](https://wade000910.github.io/Basketball-MVP-System/coach/?demo=1) · [網站首頁](https://wade000910.github.io/Basketball-MVP-System/) · [產品路線圖](./ROADMAP.md)

## 開始使用

1. 開啟球員訓練室，輸入自訂學員代碼，例如 P001。
2. 選擇罰球、中距離或三分球，設定目標球數與今天的練習重點；中距離與三分球可再選左側、中央或右側。
3. 每次投籃後，由自己或教練按大按鈕「命中」或「未中」。畫面會顯示已記錄的球次；誤記時可撤回、修正或刪除。
4. 結束練習，查看命中率、同類型上一組的比較及本組動作摘要，下載報告或列印成 PDF。
5. 下次使用相同代碼，回看近七天進度，或按「同設定再練一組」繼續練習。

第一次使用可以先開啟示範報告，熟悉操作。示範報告使用合成資料，與自己的訓練紀錄分開。

## 功能

| 功能 | 使用方式 |
| --- | --- |
| 球員首頁 | 查看近七天進度、最近 10 組命中率折線與各位置累積 |
| 投籃練習 | 設定 10、20 或 30 球目標及投籃位置，以大按鈕記錄命中與未中 |
| 紀錄修正 | 撤回最後一球，或修正、刪除指定球次 |
| 訓練報告 | 一起回看命中紀錄與同組動作摘要，下載 JSON、CSV 或列印 PDF |
| 歷史紀錄 | 保存最近 30 組，重新開啟頁面可接續練習或回看報告 |
| 罰球動作分析 | 自動填入訓練代碼，依入鏡提示調整拍攝，選擇聲音或視覺回饋 |
| 影片回看 | 匯入已下載的影片與分析資料，逐格檢視、對齊與標記事件 |
| 備份與匯入 | 下載全部訓練備份，或將 JSON 報告匯入另一台裝置 |
| 命中與動作配對 | 每一球依時間對到一次動作分析，比較命中與未中時的出手時序 |
| 雲端備份 | 登入後自動同步，換手機可還原（選用） |
| 球隊與教練總覽 | 邀請碼加入球隊；教練查看全隊練習量、趨勢、需要關心的球員與動作穩定度 |

## 場邊記錄與趨勢

按下命中或未中後，會顯示「已記錄第幾球」及下一球編號。快速重複按壓會只記一球，誤記可立即按「撤回最後一球」重新記錄。

投籃位置以球員面向籃框的方向區分，每組固定一個位置；換位置時可開始新一組。罰球固定為中央。位置會保存在歷史、JSON、CSV 與完整備份；舊的中距離或三分紀錄保持「未標記」。

在球員首頁選擇投籃類型與位置，即可查看有投籃紀錄的最近 10 組命中率折線及逐組球數。各位置命中率依總命中／總球數計算，使用此瀏覽器保存的全部已完成紀錄。報告的上一組比較限同代碼、同類型與同位置。

## 相機與影片

在罰球練習中按「開啟罰球動作分析」，會另開分析頁並帶入本組代碼。選擇慣用手與回饋方式，按「開啟相機並開始」。將手機固定在慣用手側，讓肩膀到腳踝入鏡，依畫面提示調整位置。

停止分析後，回訓練室即可看到本組動作摘要；JSON 訓練報告和完整備份會包含這些摘要。每次分析最多保存 200 個試次，本機動作摘要保留最近 30 次；影片仍需在分析頁另行下載。命中結果由你或教練手動記錄，報告會依時間把每一球對到對應的動作（見下方「命中與動作配對」）。

訓練代碼已自動填入。需要調整代碼、相機縮放、查看裝置資訊或逐次 CSV 時，可展開進階選單。從訓練室開啟的學員與訓練代碼會固定，保持報告歸屬一致。

動作頁的 Δt 表示「手肘伸展起始時間－膝部伸展角速度峰值時間」，用於回看兩個動作的先後與間隔。聲音依畫面顯示的時序區間切換。

需要回看影片時，在動作頁下載本機影片與資料套件，再前往[影片回看工具](https://wade000910.github.io/Basketball-MVP-System/offline-review/)選取同組檔案，依指引設定時間對齊。

## 球隊與教練總覽

1. 教練在訓練室的「雲端備份與球隊」註冊登入，設定顯示名字，建立球隊，取得 8 碼邀請碼。
2. 球員登入後輸入邀請碼加入。加入後，教練可以看到他的練習紀錄；球員可隨時退出，退出後教練就看不到。
3. 教練開啟[教練總覽](https://wade000910.github.io/Basketball-MVP-System/coach/)：近 7 天出席與出手、每週練習量與命中率、需要關心的球員（7 天以上沒練習）、各類命中率、罰球趨勢，點選球員可看命中與未中時的出手時序。
4. 想先看看樣子，可開啟[示範球隊](https://wade000910.github.io/Basketball-MVP-System/coach/?demo=1)（合成資料）。

雲端只保存訓練摘要（命中紀錄與動作時序），**影片不會上傳**。權限由資料庫的 Row Level Security 執行：球員只能寫自己的資料，教練只能讀目前隊員的資料。設定方式見 [supabase/README.md](./supabase/README.md)。

## 命中與動作配對

在罰球練習中同時開啟動作分析時，訓練室會把每一球依記錄時間對到一次動作：保持先後順序、同一次動作只用一次，誤觸發或漏判會跳過而不會讓後面的球全部錯位。報告會分開列出命中與未中時的平均時序差與標準差，CSV 也會附上每一球對應的動作狀態與時序。球數少時差異可能只是偶然，只供回看參考。

## 準確度驗證（慢動作對照）

[慢動作對照頁](https://wade000910.github.io/Basketball-MVP-System/validation/) 用另一支手機的 240 fps 慢動作影片當對照：逐格標記膝、肘與出手事件，載入分析頁匯出的試次 CSV，頁面會逐球配對並計算平均差、95% 一致性界限與 Bland-Altman 圖，同時比較「起始」與「峰值」兩種時序定義。拍攝與標記步驟見 [驗證流程](./docs/validation-protocol.md)；系隊試用與問卷見 [試用計畫](./docs/field-trial-protocol.md)。

## 換裝置與備份還原

登入雲端後會自動同步，換手機登入即可還原。未登入時可用以下方式手動備份：

在訓練室的「備份與匯入」按「下載全部訓練備份」，將 JSON 保存至自己的裝置。到另一台裝置開啟訓練室，選取這份檔案即可還原歷史與未完成練習；單組 JSON 訓練報告也可匯入。

匯入前會檢查資料格式與訓練歸屬。相同訓練代碼保留目前裝置的版本；若與正在進行的練習衝突、超過 30 組歷史或檔案超過 5 MB，會提示原因並保留原紀錄。示範報告不會匯入正式歷史。

## 裝置與資料保存

- 手機或電腦皆可開啟；Android 使用 Chrome，iPhone 使用 Safari。
- 訓練頁不需要相機。動作分析頁需要網路連線、HTTPS 與相機權限。
- 命中由使用者或教練手動記錄，統計會隨修正同步更新。
- 未登入時，紀錄保存在目前裝置與瀏覽器；登入後另有雲端備份。共用裝置可看到本機歷史，用完請登出並清除紀錄。
- 使用自訂代碼即可，請勿輸入真實姓名。清除網站資料會刪除紀錄，建議定期下載報告。
- 影片與分析檔由使用者在本機下載及選取，檔案不會上傳至伺服器。

## 本機開發

以本機 HTTP 伺服器開啟儲存庫，進入 training/。相機功能請使用 localhost 或 HTTPS。

程式檢查：

```bash
npm test                 # Node 單元測試、HTML 與頁面檢查
supabase/tests/run.sh    # 資料庫權限測試（需 PostgreSQL 16）
node tools/validation-browser-check.cjs  # 慢動作對照頁（需 ffmpeg 與 Playwright）
```

瀏覽器流程檢查需 Node.js 22 以上及 Chrome／Chromium，設定 BROWSER_BIN 後執行：

```bash
node tools/training-browser-smoke.cjs
```

瀏覽器流程檢查包含雲端登入、加入球隊、同步、換裝置還原與教練總覽，以記憶體版後端（`tools/cloud-fake.js`）模擬 Supabase。
